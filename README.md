# Witcher Senses Edit for Scavenger Sense

An add-on for [Scavenger Sense](https://www.nexusmods.com/skyrimspecialedition/mods/188380) (0.10.1 beta): its settings and controls
as a hunter's sense: tap the left trigger or press G to turn it on and off (not on a mount), crouch to read footprints, and a target you hit with an
arrow from a bow is tracked until it dies. See `dist/README.txt` for what it does and
`source/main.cpp` for how it drives Scavenger Sense's own tracking function.

Version 1.0.0
