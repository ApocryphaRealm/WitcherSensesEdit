# Scavenger Sense - Arrow Quarry

A patch for [Scavenger Sense](https://www.nexusmods.com/skyrimspecialedition/mods/188380) (0.10.1 beta): a target you hit
with an arrow from a bow is tracked, and stops being tracked when it dies. See `dist/README.txt` for what it does and
`source/main.cpp` for how it drives Scavenger Sense's own tracking function.

Version 1.0.0
